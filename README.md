# SkillBridge – Internship & Job Application Management System

SkillBridge is a full-stack Java web application that connects students and freshers with recruiters for internship and job opportunities.

Students can discover and apply for opportunities, manage their profiles, track applications, save jobs, and view interviews. Recruiters can post jobs, manage applicants, update application status, and schedule interviews.

## 🚀 Features

### 🎓 Student

- Registration and login
- BCrypt password encryption
- Profile management
- Education and skills management
- Resume, GitHub, LinkedIn and portfolio links
- Job and internship search
- Job filtering
- Apply for jobs with cover letter
- Application status tracking
- Save/bookmark jobs
- Interview schedule management

### 💼 Recruiter

- Recruiter registration and login
- Company profile management
- Create, edit and manage job postings
- Internship and full-time job posting
- View and filter applicants
- Review candidate profiles
- Update application status
- Add candidate feedback
- Schedule interviews
- Online, In-Person and Phone interview modes

### 🛡️ Admin

- Admin dashboard
- Platform statistics
- Student account management
- Recruiter account management
- Job moderation
- Application monitoring
- Activate/deactivate accounts
